# サンプル相性診断機能 仕様書

> **Note**: これは本テンプレートリポジトリに含まれるサンプル実装の仕様書です。FSD 各レイヤーの実装例として参照してください。実際のアプリを作る際は本機能ごと削除して構いません。

## 1. 機能概要

| 項目 | 内容 |
|---|---|
| 機能名 | サンプル相性診断 |
| コンセプト | 2つのサンプルアイテムの「相性」を診断する、テンプレート学習用のデモ機能 |
| 表示形式 | 相性スコアを％で表示 |
| 特徴 | 計算ロジックをフロントエンドに露出しない設計（BFF構成）、外部APIには依存せずテンプレート内で完結 |
| アクセスパス | `/sample/match` |

---

## 2. システム構成

```
[フロントエンド]  ←→  [BFF (routes/api/sample)]
```

| レイヤー | 役割 |
|---|---|
| フロントエンド | ID入力・結果表示のみ |
| BFF | サンプルアイテムデータの参照・相性計算 |

---

## 3. リクエストフロー

```
【フロントエンド】                【BFF (routes/api/sample)】
      |                             |
      | ① ID×2を送信               |
      |  { id_a: 1, id_b: 2 }      |
      |────────────────────────────>|
      |                             | ② サンプルアイテムの属性を参照
      |                             |   + SHA-256で相性計算
      |                             |
      | ③ 計算結果のみ返却          |
      |  { score: 73,               |
      |    name_a: "Sample Item 01",|
      |    name_b: "Sample Item 02",|
      |    color_a: "#e63f3f",      |
      |    color_b: "#3f5fe6" }     |
      |<────────────────────────────|
      |                             |
      | ④ 結果を表示               |
```

## 4. API仕様

### 4-1. フロントエンド → BFF

**エンドポイント（アイテム一覧）**
```
GET /api/sample/items
```

**エンドポイント（相性診断）**
```
POST /api/sample/match
```

**リクエストボディ**
```json
{
  "id_a": 1,
  "id_b": 2
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| id_a | number | サンプルアイテムAのID |
| id_b | number | サンプルアイテムBのID |

**レスポンスボディ**
```json
{
  "score": 73,
  "name_a": "Sample Item 01",
  "name_b": "Sample Item 02",
  "color_a": "#e63f3f",
  "color_b": "#3f5fe6"
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| score | number | 相性スコア（0〜100） |
| name_a | string | サンプルアイテムAの名前 |
| name_b | string | サンプルアイテムBの名前 |
| color_a | string | サンプルアイテムAの表示色（hex） |
| color_b | string | サンプルアイテムBの表示色（hex） |

> ⚠️ 計算に使用した属性や中間データは一切返却しない

---

## 5. 相性計算ロジック（BFF内部）

> ⚠️ このセクションはBFF内部の実装詳細。フロントエンドには非公開。

### 計算方式：SHA-256ハッシュ

- 各アイテムの属性（category / tag / color）を文字列に変換して結合
- 結合した文字列をSHA-256でハッシュ化
- ハッシュ値の先頭バイトを0〜100にマッピングしてスコアとする
- 同じID組み合わせは常に同じスコアを返す（再現性あり）
- AB と BA は同じ結果になるよう順番を正規化する（id の小さい方を先にする）

## 6. フロントエンド仕様

### 画面構成（シンプル版）

```
┌─────────────────────────────┐
│  サンプル相性診断            │
│                             │
│  [アイテムA]   [アイテムB]   │
│                             │
│      [ 比較する ボタン ]     │
│                             │
│  ┌─────────┐  ┌─────────┐  │
│  │ 色A     │  │ 色B     │  │
│  │ 名前A   │  │ 名前B   │  │
│  └─────────┘  └─────────┘  │
│                             │
│       ✨ 相性: 73%          │
└─────────────────────────────┘
```

### インタラクション

| アクション | 挙動 |
|---|---|
| ボタン押下 | BFFへリクエスト送信・ローディング表示 |
| 結果取得 | アイテムの色・名前・スコアを表示 |
| エラー時 | IDが存在しない場合はエラーメッセージ表示 |
